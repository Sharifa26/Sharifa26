**Tech Stack:**
`Python` · `FastAPI` · `FAISS` · `SentenceTransformers` · `Google Gemini API` · `BeautifulSoup`

### RAG Pipeline

```text
Documents / Web Pages
        ↓
    Data Extraction
        ↓
      Chunking
        ↓
     Embeddings
        ↓
    FAISS Vector Store
        ↓
  Semantic Similarity Search
        ↓
   Relevant Context
        ↓
      Gemini LLM
        ↓
     Final Answer
```

### Key Concepts

* 🔎 Semantic search
* 🧠 Text embeddings
* 🗃️ Vector search using FAISS
